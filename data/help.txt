MKV trim for all your lazy remuxing needs!
Traverses input file/directory (current directory if none specified) and executes one of the supported commands.
At least -a or -s argument is required.

Commands:
 [scan]    =>  Prints a track table showing which tracks would be enabled [+] or disabled [ ] by the
               'smart' command. No files are modified.
 [smart]   =>  Enables the highest-weight track per language. Tracks are scored by name keywords, codec,
               and channel count. At least one audio track is always preserved.
 [trim]    =>  Enables only tracks matching the specified languages. At least one audio track is always
               preserved.

Options:
  -a / --audio       Audio languages to keep. Comma-separated: -a eng,jpn
                     Accepts 3-letter ISO 639-2/3 codes. Invalid codes are skipped.
  -s / --subtitle    Subtitle languages to keep. Comma-separated: -s eng,jpn
                     Accepts 3-letter ISO 639-2/3 codes. Omit to remove all subtitles.
  -o / --output      Output file path (overrides Trim/ folder default)
  -W / --weights     Path to custom JSON weights file
  -R / --recursive   Scan subdirectories
  -L / --inplace     Replace files in place (no Trim folder created)
  -S / --stats       Print approximate total disk space saved
  -P / --perfile     Print approximate space diff per file
  -d / --dry         Print mkvmerge commands without executing
  -I / --interactive Ask confirmation before processing each file (smart/trim, no-op with -d)
  -V / --version     Print version (no command required)

Usage notes:
  Input path can be passed as the last argument without -i: mkv_trim scan -Ra eng /path
  Boolean flags can be combined: -RS, -Rd, -RSd, -RId
  Multiple -a/-s flags are merged and deduplicated: -a eng -a jpn  =>  [eng, jpn]

Examples:
  mkv_trim scan -Ra eng,jpn /movies        Scan all files recursively, show track table
  mkv_trim smart -Ra eng,jpn /movies       Smart-select best eng+jpn audio, recurse
  mkv_trim smart -Ra eng -s eng,jpn /f     Smart audio eng, keep eng+jpn subtitles
  mkv_trim trim -a eng,jpn -s eng /f       Dumb trim: keep eng+jpn audio, eng subs
  mkv_trim smart -RLa eng,jpn /movies      Smart select, replace files in place
  mkv_trim smart -RSda eng,jpn /movies     Dry run with stats, no files modified

Weighting (smart command):
  Track score = channel count + forced/default flags + name keyword match + codec match.
  Override weights by passing a JSON file via -W. Supported keys:

  {
    "track_name": {
      "dub": 100,
      "orig": 100,
      "comment": -1000
    },
    "audio_codec": {
      "TrueHD": 70,
      "DTS": 50,
      "AC3": 40
    },
    "subtitle_codec": {
      "ass": 20,
      "srt": 10
    }
  }
